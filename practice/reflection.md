# Git workflow reflection

Write at least one complete sentence for each answer. Each answer must contain at least 20 characters.

## 1. What is the difference between a commit and a push?

Answer: A commit saves your code changes locally in Git, while a push uploads those committed changes to a remote repository like GitHub.

## 2. Why work on a branch instead of directly on `main`?

Answer: Working on a branch lets you make changes without messing up the main code, so you can test everything before adding it to main. 

## 3. What does a pull request make possible?

Answer: A pull request lets you share your changes with others so they can review your work and approve it before merging it into the main code. 

## 4. Which Git command helped you understand the repository's state, and what did it show you?

Answer: The git status command helped me understand the repository's state because it showed me which files had changes, which files were ready to commit, and whether my branch was up to date.
